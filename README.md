# Scroll Driven City Sunset

Quero que você prepare esse sistema de uma forma que vai ficar em versão cinematografica. Prepare de uma forma que ao rolar o scroll pra baixo, vai entardecer a cidade no fundo e vai ter movimentos reais. Ao rolar pra cima o scroll vai amanhecer e ter movimentos reais. Prepare de uma forma que cada função ai sera utilizavel de forma eficiente e eficaz sem ter erros. Quero algo mais humano possivel e sem deixar com cara generica
